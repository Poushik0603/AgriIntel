# AgriIntel

Repository layout:

- `frontend` - React web app
- `backend` - microservices, API gateway, service registry, Kubernetes manifests, Maven parent, and Docker Compose

## Run

Backend:

1. `cd backend`
2. Start your services with Docker Compose or Maven from there

Frontend:

1. `cd frontend`
2. `npm install`
3. `npm run dev`
